# 0018 · Leo 常用服务分组

YouTube 和 Netflix 各有一个手选组，首选「流媒体」，可分别指定地区。「游戏下载」首选 DIRECT，覆盖目录声明的 Steam、Epic 和 Xbox 下载主机。三个组复用现有出口，客户端可以单独保存选择。其他影音、社交服务沿用共享组，需要独立出口时由 ServiceRoute 生成。Mihomo 产物用 YAML 锚点复用相同顺序的长成员列表。

默认模板预算从 185 条规则调整为 200 条。固定 144 节点 SS 夹具从 17 组调整为 20 组，成员边上限从 425 调整为 440。沿用 9 个外部 Provider、6 个健康检查组、235 个探针成员和 37 KiB 产物上限。

在同一台机器上使用 Mihomo v1.19.32 交替启动两版合成配置，各 7 轮。每轮使用新的规则缓存、相同的本地 geodata，并由本机 HTTP 服务提供与公开审计摘要一致的规则文件。从进程启动计时，直至控制器报告 9 个 Provider 全部加载。
